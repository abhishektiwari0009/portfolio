# Abhishek Tiwari - Modern Developer Portfolio 🚀

A modern, responsive, dark-glassmorphism developer portfolio built with **100% Pure HTML5 & CSS3** (Zero JavaScript, no complex build steps).

## 📂 Project Structure

```text
abhishek-portfolio/
├── index.html       # The complete structure & content
├── style.css        # Modern CSS3 styles, glassmorphism, animations & media queries
└── README.md        # Beginner guide on editing & deploying
```

---

## ⚡ How to Open & Preview

1. **Directly in Browser**: Double-click `index.html` to open it in Chrome, Edge, Brave, or Firefox.
2. **In VS Code**: Right-click `index.html` and choose **"Open with Live Server"** (if you have the Live Server extension).

---

## ✏️ How to Customize

### 1. Update Your Links
Open `index.html` and replace the placeholder URLs:
- **GitHub**: Search for `https://github.com` and replace with your GitHub profile link (e.g., `https://github.com/your-username`).
- **LinkedIn**: Search for `https://linkedin.com` and replace with your LinkedIn profile link.
- **Email & Phone**: Search for `at455724@gmail.com` and `6375127385` to modify contact info.

### 2. Add or Edit Projects
In `index.html`, scroll down to `<section id="projects">`. Each project is wrapped in an `<article class="project-card">` block. You can copy-paste that block to add more projects!

### 3. Change Theme Colors
In `style.css`, at the very top under `:root`, you can change the accent colors:
```css
--accent-blue: #6366f1;   /* Primary accent */
--accent-cyan: #06b6d4;   /* Secondary accent */
--accent-emerald: #10b981;/* Status badge glow */
```

## 🌐 Free Deployment (GitHub Pages)

1. Create a repository on [GitHub](https://github.com) named `portfolio` (or `username.github.io`).
2. Upload `index.html` and `style.css`.
3. Go to **Repository Settings** > **Pages** > Select `main` branch > Click **Save**.
4. Your website will be live at `https://yourusername.github.io/portfolio`!
